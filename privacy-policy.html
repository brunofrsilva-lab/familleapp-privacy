Politique de Confidentialité

FamilleApp — BraquelApps

👋 Introduction

Bienvenue sur FamilleApp. Cette politique explique comment nous collectons, utilisons et protégeons vos données personnelles lorsque vous utilisez notre application.

En utilisant FamilleApp, vous acceptez les pratiques décrites dans ce document. Si vous n'acceptez pas ces conditions, veuillez ne pas utiliser l'application.

Responsable du traitement : Bruno Filipe Rocha e Silva (BraquelApps)
Contact : Creator_apps@protonmail.com
Pays : Suisse

📊 Données collectées

Données de compte

  • Adresse email (parents uniquement)
  • Prénom
  • Mot de passe (hashé, jamais stocké en clair)
  • Photo de profil (optionnelle)
  • Rôle dans la famille (parent ou enfant)

Comptes enfants

Les comptes enfants utilisent un email généré automatiquement (format child_xxx@familleapp.app), invisible pour l'utilisateur. Ce compte est créé et géré exclusivement par un parent.

Données familiales

  • Rendez-vous et congés du calendrier familial
  • Liste de courses partagée
  • Tâches et points des enfants
  • Menu de la semaine
  • Trajets (départs et arrivées)
  • Contacts importants
  • Informations sur les animaux de compagnie

Données techniques

  • Token de notification push (par appareil)
  • Identifiant de session Supabase
  • Logs d'erreurs anonymisés

🔔 Notifications Push & Firebase

FamilleApp utilise Firebase Cloud Messaging (Google) pour envoyer des notifications push entre membres de la famille.

  • Un token d'appareil unique est généré à l'installation
  • Ce token est stocké dans notre base de données Supabase
  • Il est utilisé uniquement pour envoyer des notifications aux membres de votre famille
  • Un appareil peut avoir plusieurs tokens (si plusieurs comptes sont utilisés)
  • Les tokens sont supprimés lors de la suppression du compte
Firebase est un service de Google LLC. Sa politique de confidentialité est disponible sur firebase.google.com/support/privacy

🤖 Intelligence Artificielle (Kelly)

L'assistant Kelly utilise des services IA tiers selon votre configuration :

  • Google Gemini — Google LLC
  • Claude — Anthropic
  • OpenAI GPT — OpenAI

Les données envoyées à ces services incluent : votre agenda de la semaine, vos tâches, votre liste de courses et vos menus planifiés. Ces données sont utilisées uniquement pour générer des conseils personnalisés.

Les appels IA transitent par un proxy sécurisé (Supabase Edge Functions) — votre clé API n'est jamais exposée côté client.

🔗 Deep Links

FamilleApp prend en charge les liens d'invitation de type familleapp://join?code=XXX. Ces liens permettent à un nouveau membre de rejoindre une famille en un tap. Aucune donnée personnelle n'est transmise via ces liens.

🗄️ Stockage des données

Vos données sont stockées sur Supabase, une plateforme cloud sécurisée :

  • Serveurs situés en Europe
  • Chiffrement en transit (HTTPS/TLS)
  • Chiffrement au repos
  • Accès restreint par politique RLS (Row Level Security)
  • Chaque famille accède uniquement à ses propres données

Les photos de profil sont stockées dans Supabase Storage (bucket privé).

Certaines données sont également stockées localement sur votre appareil via AsyncStorage et SecureStore (données de session, préférences).

💳 Abonnement & Paiements

FamilleApp propose un abonnement premium via RevenueCat et le Google Play Store.

  • Les paiements sont traités exclusivement par Google Play
  • FamilleApp ne collecte ni ne stocke aucune donnée de paiement
  • RevenueCat est utilisé pour vérifier le statut d'abonnement

Politique de RevenueCat : revenuecat.com/privacy

🔒 Sécurité

  • Mots de passe hashés avec SHA-256 avant stockage
  • Sessions sécurisées via SecureStore (chiffrement natif Android)
  • Clés API stockées localement, jamais transmises à nos serveurs
  • Politique RLS Supabase : chaque famille est isolée
  • Clés Firebase restreintes au package com.braquelapps.familleapp

👨‍👩‍👧 Protection des enfants

FamilleApp permet la création de comptes enfants, gérés exclusivement par les parents.

  • Les enfants ne fournissent pas d'email — un email fictif est généré automatiquement
  • Les comptes enfants sont créés et contrôlés par un parent
  • Les enfants n'ont accès qu'aux données familiales partagées
  • Aucune donnée enfant n'est partagée avec des tiers
  • Conformité COPPA et RGPD assurée

⚖️ Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier des données inexactes
  • Supprimer votre compte et toutes vos données
  • Portabilité de vos données
  • Opposition au traitement de vos données
Pour supprimer votre compte : Réglages → Supprimer mon profil dans l'application.
Ou via notre page dédiée : Page de suppression
