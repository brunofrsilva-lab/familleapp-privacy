1. Données collectées

Uniquement ce qui est nécessaire au bon fonctionnement de l'app

  • Compte & profil — Adresse email, prénom, photo de profil (optionnelle), rôle dans la famille (parent / enfant)
  • Données familiales — Événements agenda, tâches, liste de courses, menu de la semaine, récompenses, trajets
  • Localisation — Uniquement lorsque vous partagez un trajet en temps réel (fonctionnalité "Départ"). Non collectée en arrière-plan.

  • Données d'abonnement — Statut Premium via RevenueCat. Aucune donnée bancaire n'est stockée par FamilleApp.
  • Données IA (Kelly) — Résumés anonymisés de votre semaine envoyés à Google Gemini pour générer des conseils. Voir section 3.
ℹ️
Nous ne collectons pas : numéro de téléphone, données de navigation, identifiants publicitaires, ou toute donnée non listée ci-dessus.

3. Kelly IA & Google Gemini

Comment fonctionne l'intelligence artificielle dans FamilleApp

Kelly est l'assistante IA intégrée à FamilleApp. Elle utilise Google Gemini (gemini-2.5-flash-lite) pour analyser votre semaine et générer des conseils personnalisés.

🔐
Architecture sécurisée : Votre clé API n'est jamais dans l'application. Les requêtes passent par un proxy sécurisé (Supabase Edge Function) — votre app ne communique jamais directement avec Google.

Ce qui est envoyé à Google Gemini :

  • Résumé de semaine — Nombre de tâches, événements à venir, menu prévu (pas de noms complets, pas d'emails)
  • Messages du chat Kelly — Vos questions et les prénoms des membres (pas d'informations sensibles)
⚠️
Important : Les données envoyées à Google Gemini sont soumises à la Politique de Confidentialité de Google. Nous vous recommandons de ne jamais inclure d'informations sensibles (numéros de sécurité sociale, mots de passe) dans vos messages à Kelly.

5. Protection des enfants

Mesures spécifiques pour les mineurs (RGPD Art. 8)

FamilleApp est conçue pour être utilisée par des familles avec enfants. Nous prenons la protection des données des mineurs très au sérieux.

  • Consentement parental — Les comptes enfants sont créés et contrôlés par un parent. L'enfant se connecte avec un code famille fourni par le parent.
  • Données minimales — Pour les enfants, nous collectons uniquement le prénom, un avatar optionnel et les points/tâches liés à leur profil.
  • Validation parentale des tâches — Les tâches proposées par un enfant sont soumises à l'approbation d'un parent avant d'apparaître dans la liste familiale. Aucune tâche n'est visible par la famille sans validation explicite d'un parent.
  • Permissions limitées — Les enfants ne peuvent pas modifier ni supprimer les rendez-vous, congés ou profils créés par un parent. Ils peuvent uniquement gérer leurs propres entrées.
  • Aucune publicité — FamilleApp n'affiche aucune publicité, pour les adultes comme pour les enfants.
  • Suppression immédiate — Un parent peut supprimer le profil d'un enfant à tout moment depuis les Réglages.
⚠️
Si vous pensez qu'un enfant a créé un compte sans consentement parental, contactez-nous immédiatement à contact@braquelapps.com pour suppression.
🔐

6. Sécurité des données

Comment nous protégeons vos informations

  • Chiffrement en transit — Toutes les communications sont chiffrées via HTTPS/TLS
  • Row Level Security (RLS) — Chaque famille ne peut accéder qu'à ses propres données — impossible d'accéder aux données d'une autre famille
  • Données sensibles locales — Les tokens d'authentification sont stockés dans le Secure Store du téléphone, jamais en clair
  • Clés API sécurisées — Les clés d'API (Gemini, etc.) ne sont jamais dans l'application — stockées côté serveur uniquement
  • Authentification biométrique — Option de verrouillage par empreinte digitale ou reconnaissance faciale disponible
⚖️

8. Conservation des données

Combien de temps conservons-nous vos données

  • Compte actif — Données conservées tant que votre compte est actif
